# Digitale Grundbildung – Lernpfad Unterstufe

Online-Lernpfad für Digitale Grundbildung in der Sekundarstufe I (5.–8. Schulstufe), nach dem österreichischen Lehrplan. Die Kapitel sind verschlüsselt und werden von der Lehrkraft mit Freigabe-Codes für die Klassen freigeschaltet.

Live: https://schmidh2.github.io/digitale-grundbildung-lernpfad/
